# Массовая загрузка трек-кодов

## Обзор

Модуль массовой загрузки трек-кодов позволяет администраторам быстро добавлять множество товаров в систему тремя способами:

1. **Список трек-кодов** — ввод через Telegram списком
2. **Excel файл** — загрузка структурированных данных из .xlsx
3. **Ручной ввод** — добавление одного трек-кода вручную

## Архитектура

### Компоненты

```
services/
├── bulk_import.py          # Основной сервис импорта
│   ├── BulkImportService   # Класс-сервис для импорта
│   ├── BulkImportResult    # Результат импорта
│   └── TrackCodeValidator  # Валидация трек-кодов
└── excel_template.py       # Генератор шаблонов Excel

handlers/admin/
└── bulk_import.py          # Обработчики Telegram

utils/
└── states.py               # FSM состояния (BULK_IMPORT_*)

keyboards/admin.py          # Клавиатуры для админа
```

### Слои

1. **Презентационный слой** (`handlers/admin/bulk_import.py`)
   - Обработка callback-запросов
   - Взаимодействие с пользователем через Telegram
   - Валидация файлов

2. **Бизнес-логика** (`services/bulk_import.py`)
   - Парсинг и валидация трек-кодов
   - Импорт из текста и Excel
   - Формирование отчётов

3. **Слой данных** (`database/repository.py`)
   - ProductRepository для работы с БД
   - Проверка дубликатов
   - Создание товаров

## Использование

### 1. Список трек-кодов

Администратор может ввести трек-коды списком:

```
TRACK001, TRACK002, TRACK003
```

или с новой строки:

```
TRACK001
TRACK002
TRACK003
```

**Особенности:**
- Автоматическое удаление дубликатов в списке
- Поддержка разделителей: запятая, точка с запятой, пробел, новая строка
- Приведение к верхнему регистру

### 2. Excel файл

Структура файла (.xlsx):

| Трек-код* | Название товара | Категория | Количество | Цена USD | Вес кг | Страна |
|-----------|----------------|-----------|------------|----------|--------|---------|
| TRACK001  | Смартфон       | электроника | 1       | 299.99   | 0.5    | China   |
| TRACK002  | Кроссовки      | обувь     | 2          | 89.50    | 1.2    | China   |

**Колонки:**
- **A (Трек-код)** — обязательно
- **B (Название)** — опционально
- **C (Категория)** — опционально
- **D (Количество)** — опционально, по умолчанию 1
- **E (Цена)** — опционально, по умолчанию 0.0
- **F (Вес)** — опционально, по умолчанию 0.0
- **G (Страна)** — опционально, по умолчанию China

**Категории:**
- `электроника` / `electronics`
- `одежда` / `clothing`
- `обувь` / `shoes`
- `бытовая техника` / `home_appliances`
- `косметика` / `beauty`
- `игрушки` / `toys`
- `автозапчасти` / `automotive`
- `спорттовары` / `sports`
- `другое` / `other`

### 3. Ручной ввод

Добавление одного трек-кода с базовыми параметрами:
- Название: "Товар {TRACK_CODE}"
- Категория: "other"
- Страна: "China"
- Статус: "CREATED"

## Валидация

### Правила валидации трек-кода

```python
- Минимум 6 символов
- Максимум 50 символов
- Допустимые символы: A-Z, 0-9, дефис (-)
- Регистр не важен (автоматически в верхний)
```

### Обработка ошибок

Система различает три типа результатов:

1. **Успех** — трек-код успешно добавлен
2. **Дубликат** — трек-код уже существует в БД
3. **Ошибка** — невалидный формат или ошибка БД

## Уведомления пользователей

При успешном импорте трек-кода система автоматически:

1. Проверяет pending трек-коды в `user_track_codes`
2. Активирует их (PENDING → ACTIVE)
3. Отправляет уведомление пользователям:

```
📦 Ваш трек-код TRACK001 зарегистрирован!

🏷️ Товар: Смартфон Samsung
📍 Статус: Создан
```

## Производительность

### Оптимизации

1. **Асинхронные запросы** — все операции БД async
2. **Транзакции** — один session на весь импорт
3. **Ограничения** — максимум 10MB для Excel файлов
4. **Логирование** — детальное логирование для отладки

### Ограничения

- Максимальный размер Excel: 10 MB
- Рекомендуемое количество за раз: до 1000 трек-кодов
- Timeout операции: стандартный для async_session

## Примеры кода

### Использование сервиса

```python
from services.bulk_import import BulkImportService
from database.repository import ProductRepository

async with async_session_maker() as session:
    product_repo = ProductRepository(session)
    import_service = BulkImportService(product_repo)

    # Импорт из текста
    result = await import_service.import_from_text(
        text="TRACK001, TRACK002, TRACK003",
        user_id=123456,
        default_category="electronics",
        default_country="China"
    )

    # Импорт из Excel
    result = await import_service.import_from_excel(
        file_path="import.xlsx",
        user_id=123456
    )

    # Получение отчёта
    summary = result.get_summary(language="ru")
    print(summary)
```


## Troubleshooting

### Проблема: Excel файл не обрабатывается

**Решение:**
- Проверьте расширение (.xlsx, .xls)
- Убедитесь, что размер < 10 MB
- Проверьте права на запись в директорию `temp/`

### Проблема: Дубликаты не игнорируются

**Решение:**
- Проверьте логи — должна быть запись "Дубликат: {track_code}"
- Убедитесь, что трек-коды уникальны в БД

### Проблема: Уведомления не отправляются

**Решение:**
- Проверьте логи активации pending трек-кодов
- Убедитесь, что у пользователей есть записи в `user_track_codes`
- Проверьте права бота на отправку сообщений
