# Руководство администратора — Массовая загрузка трек-кодов

## Быстрый старт

### Способ 1: Список трек-кодов через Telegram

1. Откройте бота и перейдите в админ-панель
2. Нажмите **📥 Массовая загрузка**
3. Выберите **📝 Список трек-кодов**
4. Введите трек-коды через запятую или с новой строки:
   ```
   TRACK001, TRACK002, TRACK003
   ```
5. Получите отчёт о результатах импорта

### Способ 2: Excel файл

1. Откройте бота → **📥 Массовая загрузка**
2. Нажмите **📥 Скачать шаблон Excel**
3. Откройте полученный файл и заполните данные:
   - **Колонка A (обязательно):** трек-код
   - **Колонка B:** название товара
   - **Колонка C:** категория (электроника, одежда, обувь и т.д.)
   - **Колонка D:** количество
   - **Колонка E:** цена в USD
   - **Колонка F:** вес в кг
   - **Колонка G:** страна отправления
4. Сохраните файл
5. Вернитесь в бот → **📥 Массовая загрузка** → **📄 Excel файл**
6. Отправьте заполненный файл
7. Получите подробный отчёт

### Способ 3: Ручной ввод

1. **📥 Массовая загрузка** → **✍️ Ручной ввод трек-кода**
2. Введите один трек-код (например: TRACK12345)
3. Товар будет создан с базовыми параметрами

## Требования к трек-коду

✅ **Допустимо:**
- Минимум 6 символов
- Максимум 50 символов
- Буквы (A-Z), цифры (0-9), дефис (-)
- Примеры: `TRACK001`, `CN240215001GN1234`, `US-12345-ABC`

❌ **Не допустимо:**
- Менее 6 символов: `TR123`
- Спецсимволы: `TRACK@001`, `TRACK#123`
- Пробелы внутри: `TRACK 001`

## Часто задаваемые вопросы

### 1. Что делать, если Excel файл не загружается?

- Убедитесь, что файл имеет расширение `.xlsx` или `.xls`
- Проверьте размер файла (максимум 10 MB)
- Попробуйте пересохранить файл в Excel

### 2. Как обновить данные уже загруженного товара?

Массовая загрузка пропускает дубликаты. Для обновления используйте:
- **🔄 Обновить статусы** для изменения статуса
- Ручное редактирование через основное меню

### 3. Сколько трек-кодов можно загрузить за раз?

Рекомендуется до 1000 трек-кодов за одну операцию для оптимальной производительности.

### 4. Можно ли отменить массовую загрузку?

Нет, после подтверждения товары сразу добавляются в базу. Проверяйте данные перед отправкой.

### 5. Что значит "Дубликат пропущен"?

Трек-код с таким же значением уже существует в базе данных. Система автоматически пропускает его, чтобы избежать дублирования.

## Советы по эффективной работе

1. **Используйте шаблон Excel** — в нём есть подробная инструкция
2. **Группируйте товары по категориям** — удобнее заполнять и проверять
3. **Сохраняйте копии файлов** — на случай необходимости повторной загрузки
4. **Проверяйте отчёт** — обращайте внимание на ошибки и дубликаты
5. **Используйте понятные названия** — клиенты видят название товара

## Техническая поддержка

При возникновении проблем:

1. Проверьте логи бота (если есть доступ к серверу)
2. Сохраните скриншот ошибки
3. Опишите последовательность действий
4. Отправьте проблемный Excel файл (если применимо)
